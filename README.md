## Noah Tayebwa — Portfolio

Static portfolio site showcasing work experience, skills, and links.

### Preview
- Open `index.html` in a browser or serve locally.

### Local development
You can use any static server. Example with Python:
```bash
python3 -m http.server 8080
```
Then visit `http://localhost:8080`.

### Structure
- `index.html`: Main page
- `assets/css/`: Compiled CSS themes
- `assets/scss/`: SCSS sources
- `assets/images/`: Images
- `assets/fontawesome/`: Icons JS

### Customization
- Update personal info in `index.html` (name, contacts, links).
- Switch theme by changing the stylesheet href to another `pillar-*.css`.
